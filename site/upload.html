How it works
  1. Fill in the metadata — give your document a title, select your subteam, and add the year. Author, date, tags, and description are optional but helpful.
  2. Upload your file — drag and drop or click to browse. Supported formats: PDF, Markdown, Word, LaTeX.
  3. Submit for review — this opens a pull request on GitHub. Nothing goes live yet.
  4. A team lead reviews and merges the PR — once merged, the document automatically appears on the docs site within a minute.
